# Security policy

## Supported versions

Security fixes are applied to the current release line published on [npm](https://www.npmjs.com/package/@ai-agent-ledger/sdk). Upgrade to the latest version when patches are announced.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

1. Prefer **[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)** for this repository (repo **Settings → General → Private vulnerability reporting**), if it is enabled.
2. Otherwise, email the maintainers with a clear subject line (for example `Security: AgentLedger SDK`) and include steps to reproduce, impact, and any suggested fix if you have one.

We aim to acknowledge reports within **5 business days** and coordinate disclosure after a fix is available.

## Scope

This policy applies to the **AgentLedger SDK** open-source codebase (this repository). Separate products or hosted services may use a different process; maintainers will redirect you if needed.

## Safe harbor

We appreciate responsible disclosure. If you act in good faith and avoid harming users or data, we will not pursue legal action for research that respects this policy.
